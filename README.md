## 📱 产品简介

TOMO 是一款革命性的酒店比价应用，通过AI技术为用户提供最便捷的酒店价格对比服务。无论您是通过语音指令、文字输入、图片上传，还是在OTA平台浏览时使用悬浮球功能，TOMO都能快速为您找到最优惠的酒店价格。

## ✨ 核心功能

### 🎤 多种交互方式
- **语音输入**: 说出您的需求，AI智能理解并执行比价
- **文字输入**: 输入酒店信息或比价需求
- **图片识别**: 上传酒店图片或截图，自动识别并比价
- **悬浮球触发**: 在任意OTA酒店详情页一键触发比价

### 🔍 智能比价
- 覆盖主流OTA平台（携程、去哪儿、美团等）
- 基于视觉的真实、实时价格获取
- 智能筛选最优价格和优惠信息
- 支持不同房型和入住日期的灵活比价

## 🚀 快速开始
 
### 系统要求
- Android 10.0 (API level 29) 及以上
- 网络连接
- 存储空间: 20MB
- 下载并登录OTA平台账号

### 安装方式
1. 前往 [Releases](../../releases) 页面
2. 下载最新版本的APK文件
3. 在设备上启用"未知来源"安装
4. 安装并启动应用
