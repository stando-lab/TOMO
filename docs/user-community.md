## 📋 社区规则

### ✅ 鼓励行为

**积极参与**:
- 💬 友好交流，互相帮助
- 📚 分享使用经验和技巧
- 🐛 及时反馈问题和建议
- 🎯 参与社区活动和讨论

**高质量内容**:
- 📝 详细的问题描述
- 🎥 清晰的演示截图或视频
- 💡 建设性的改进建议
- 📊 有价值的数据分析

### ❌ 禁止行为

**违规内容**:
- 🚫 发布违法违规信息
- 🚫 恶意攻击他人或应用
- 🚫 传播虚假信息
- 🚫 发布广告和垃圾信息

**不当行为**:
- 🚫 恶意刷屏或灌水
- 🚫 人身攻击或歧视言论
- 🚫 泄露他人隐私信息
- 🚫 恶意传播负面情绪

### ⚖️ 管理措施

**违规处理流程**:
1. **首次违规**: 私信提醒，删除违规内容
2. **再次违规**: 群内警告，临时禁言
3. **严重违规**: 移出群聊，永久封禁
4. **申诉渠道**: 可向管理员申诉，公平处理
