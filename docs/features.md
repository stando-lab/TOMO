# 📋 功能详解

## 核心功能介绍

### 🎤 语音比价功能

#### 使用方法
1. 点击主界面的语音按钮
2. 说出您的比价需求，例如：
   - "帮我比较北京三里屯附近的酒店价格"
   - "查找上海外滩12月25日到27日的酒店"
   - "我要订广州天河区的商务酒店"

#### 智能识别能力
- 自动识别城市、地区、入住日期
- 理解酒店类型偏好（商务、度假、经济型等）
- 支持模糊描述的智能匹配

### ✍️ 文字输入功能

#### 支持的输入格式
- 结构化输入：城市+日期+需求
- 自然语言描述
- 酒店名称直接搜索
- 地址或地标搜索

#### 智能补全
- 城市名称自动补全
- 热门地标推荐
- 历史搜索记录

### 📷 图片识别功能

#### 支持的图片类型
- 酒店外观照片
- OTA平台截图
- 酒店名片或宣传册
- 地图截图

#### 识别能力
- OCR文字识别
- 酒店品牌logo识别
- 地理位置信息提取
- 价格信息自动抓取

### 🔵 悬浮球功能

#### 激活方式
1. 开启悬浮窗权限
2. 在任意OTA应用中浏览酒店
3. 点击悬浮球一键比价

#### 支持的OTA平台
- 携程旅行
- 去哪儿旅行
- 美团
- 飞猪
- 同程旅行
- 马蜂窝
- Booking.com
- Agoda
