# ❓ 常见问题

## 🚀 安装与设置

### Q: 为什么无法安装APK文件？
**A**: 请检查以下设置：
1. 确保已开启"未知来源"安装权限
2. Android版本需要7.0及以上
3. 确保有足够的存储空间（至少50MB）
4. 如果仍无法安装，请尝试重新下载APK文件

### Q: 首次启动时需要哪些权限？
**A**: TOMO需要以下权限才能正常工作：
- **网络权限**: 获取实时酒店价格信息
- **麦克风权限**: 语音输入功能
- **相机权限**: 拍照识别功能
- **存储权限**: 保存比价结果和缓存
- **悬浮窗权限**: 悬浮球功能（可选）

### Q: 如何开启悬浮窗权限？
**A**: 不同品牌手机设置方法：
- **小米**: 设置 → 应用设置 → 应用管理 → TOMO → 权限管理 → 显示悬浮窗
- **华为**: 设置 → 应用和通知 → 权限管理 → 悬浮窗 → TOMO
- **OPPO**: 设置 → 应用管理 → TOMO → 权限 → 悬浮窗
- **vivo**: 设置 → 更多设置 → 权限管理 → 悬浮窗 → TOMO

## 🎤 语音功能

### Q: 语音识别不准确怎么办？
**A**: 提高识别准确率的方法：
1. 在安静环境下使用
2. 说话清晰，语速适中
3. 使用普通话或标准英语
4. 避免方言或过于复杂的表达
5. 可以多次尝试，系统会学习您的语音特点

### Q: 支持哪些语言的语音输入？
**A**: 目前支持：
- 中文（普通话）
- 英语
- 粤语（测试版）
- 更多语言正在开发中

### Q: 语音功能在嘈杂环境下能用吗？
**A**: TOMO具备一定的降噪能力，但建议：
- 尽量在相对安静的环境使用
- 将手机靠近嘴部
- 说话声音稍大一些
- 如果识别效果不佳，可切换到文字输入

## 📷 图片识别

### Q: 什么样的图片识别效果最好？
**A**: 最佳图片要求：
- **清晰度**: 文字清晰可见
- **光线**: 光线充足，避免阴影
- **角度**: 正面拍摄，避免倾斜
- **内容**: 包含酒店名称、地址等关键信息

### Q: 为什么有些图片识别失败？
**A**: 可能的原因：
- 图片模糊或光线不足
- 文字过小或字体特殊
- 图片中信息不完整
- 网络连接问题

**解决方法**:
- 重新拍摄更清晰的照片
- 调整拍摄角度和距离
- 确保网络连接稳定
- 可以尝试手动输入关键信息

### Q: 支持识别哪些类型的图片？
**A**: 支持识别：
- 酒店外观照片
- OTA平台截图
- 酒店名片或宣传册
- 地图截图
- 酒店预订确认单
- 旅游攻略截图

## 🔵 悬浮球功能

**A**: 检查步骤：
1. 确认已开启悬浮窗权限
2. 检查是否在支持的OTA应用中
3. 重启TOMO应用
4. 重启手机
5. 如果问题持续，请联系客服

### Q: 悬浮球在哪些应用中可以使用？
**A**: 目前支持的OTA应用：
- 携程旅行
- 去哪儿旅行
- 美团
- 飞猪
- 同程旅行
- 马蜂窝
- Booking.com
- Agoda
- 更多平台持续添加中

### Q: 悬浮球可以调整位置吗？
**A**: 可以！悬浮球支持：
- 拖拽到屏幕任意位置
- 自动吸附到屏幕边缘
- 透明度调节
- 大小调节
- 隐藏/显示切换

## 💰 价格与比价

### Q: 价格信息多久更新一次？
**A**: 
- **实时比价**: 每次搜索都获取最新价格
- **后台更新**: 每5分钟更新一次
- **深度更新**: 每小时进行一次全面更新
- **特殊时期**: 节假日等高峰期更新频率会增加

### Q: 为什么不同平台价格差异很大？
**A**: 价格差异的原因：
- **房型不同**: 同一酒店不同房型价格不同
- **政策不同**: 取消政策、早餐包含等
- **会员优惠**: 不同平台会员享受不同折扣
- **促销活动**: 限时优惠、满减活动等
- **税费包含**: 有些平台价格不含税费

### Q: 如何确保获得最优价格？
**A**: 建议策略：
1. 多平台对比，不要只看一个平台
2. 注意查看取消政策和额外费用
3. 关注会员优惠和促销活动
4. 考虑预订时间，提前预订通常更便宜
5. 使用价格监控功能，等待降价

## 📱 应用使用

### Q: 应用运行缓慢怎么办？
**A**: 优化方法：
1. 清理应用缓存
2. 关闭其他不必要的应用
3. 确保网络连接稳定
4. 重启应用
5. 检查手机存储空间
6. 更新到最新版本

### Q: 如何清理应用缓存？
**A**: 清理步骤：
- **应用内清理**: 设置 → 存储管理 → 清理缓存
- **系统清理**: 手机设置 → 应用管理 → TOMO → 存储 → 清理缓存

### Q: 应用闪退怎么解决？
**A**: 解决步骤：
1. 重启应用
2. 重启手机
3. 清理应用缓存
4. 检查系统版本兼容性
5. 重新安装应用
6. 如果问题持续，请提供崩溃日志给客服

## 🔒 隐私与安全

### Q: 我的搜索记录会被保存吗？
**A**: 隐私保护措施：
- 搜索记录仅保存在本地设备
- 不会上传个人隐私信息
- 用户可以随时清除历史记录
- 支持无痕模式搜索

### Q: 语音数据如何处理？
**A**: 语音数据处理：
- 语音转文字后立即删除音频
- 不保存原始语音文件
- 文字内容仅用于比价服务
- 符合相关隐私法规要求

### Q: 如何删除个人数据？
**A**: 数据删除方法：
- **搜索历史**: 设置 → 隐私设置 → 清除搜索历史
- **缓存数据**: 设置 → 存储管理 → 清除所有数据
- **账户数据**: 设置 → 账户管理 → 删除账户
